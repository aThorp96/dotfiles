# Custom Firefox CSS

Based on [firefox-css-hacks](https://github.com/MrOtherGuy/firefox-csshacks/tree/master).

Assumes firefox has the [Sideberry](https://addons.mozilla.org/en-US/firefox/addon/sidebery/) plugin installed

Directory should be symlinked into the Firefox profile folder:
```sh
ln -s $(pwd)/firefox-custom-css ${firefox-profile-directory}/chrome
```
